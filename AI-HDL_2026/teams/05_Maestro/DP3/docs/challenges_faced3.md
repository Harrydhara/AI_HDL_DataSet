# Challenge Faced
The main challenge we faced was determining the level of security to implement. On one hand, we can fully implement on-chip authentication, but it would cost significant area and register overhead. On the other hand, we can offload everything to the ESP32, but it would leave the SPI bus unprotected. Reconciling these two strategies was challenging because we had to choose which features to keep, discard, and combine to stay within the area and timing limitations. We also faced challenges during testing and verification. Initial testing ran into many issues with fanout, capacitance, and slew violations. With the fully implemented design, testing took longer to run, and we found it somewhat difficult to pass OpenLane testing.
