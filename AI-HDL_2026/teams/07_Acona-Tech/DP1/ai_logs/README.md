# Prompt Logs (Evidence)

Each file is kept in the following format:

## Goal
What did we want to produce?

## Prompt
The prompt (full text) sent to the model.

## Model output summary
A brief summary of the model's response and critical components.

## What we changed and why
What did we change and why? (bug fix, simplification, timing, style, etc.)

## Files impacted
Which files were impacted? (commit hash, if any)
