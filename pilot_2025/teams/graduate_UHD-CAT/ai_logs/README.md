<h3>Project Overview</h3>
<p>This project was designed and simulated using Vivado.</p>

<h3>Folder Structure</h3>
<ul>
  <li><b>Source Files:</b> Verilog design files used throughout all development phases.</li>
  <li><b>Simulation Files:</b> Testbench files used for simulation and verification.</li>  
</ul>  

<h3>Source Files</h3>
<ul>
  <li><b>top_level.v</b>: The main module that integrates all components.</li>
  <li><b>clock_divider.v</b>: Reduces the 100 MHz Basys 3 clock to 10 kHz.</li>
  <li><b>buttonDebouncer.v</b>: Ensures stable, debounced input signals for the start/stop and reset buttons and other buttons.</li>
  <li><b>seven_segment_display.v</b>: Controls the display of time on the Basys 3 four-digit seven-segment display.</li>
  <li><b>stopwatch.v</b>: Implements stopwatch functionality, including start/stop and reset features.</li>
  <li><b>digital_clock.v</b>: Implements a digital clock with adjustable time settings, depending on timezone.</li>
  <li><b>convert_12_to_24.v</b>: Converts 12-hour format input to a 24-hour format.</li>
  <li><b>alarm.v</b>: Implements an alarm module where hours, minutes, and seconds can be set independently using buttons.</li>
</ul>

<b>Note:</b> All Verilog files were generated by ChatGPT. However, some modifications were made, such as correcting incorrect port names. In certain cases, rather than copying multiple lines of code and asking ChatGPT to correct them, we made the necessary corrections ourselves to save time. Occasionally, we made mistakes while pasting the code and did not re-submit it to ChatGPT for correction. Instead, we directly corrected the output generated by ChatGPT. They were really minor things and always in our transcripts.

<h3>Simulation Files</h3>
<ul>
  <li><b>tb_top_level.v</b>: Testbench designed to verify all modules.</li>
  <li><b>tb_alarm_clock_with_digital_clock.v</b>: Testbench created to evaluate the alarm clock functionality independently.</li>
</ul>

<h3>Completion</h3>
Due to time constraints, design phases 3 and 4 could not be implemented. However, the conversations with ChatGPT have been valuable in identifying potential improvements for power and resource utilization. Implementing the suggested optimizations must be done incrementally, with thorough testing of functionality at each step. Some of these techniques may already be applied by Vivado.

<h3>Limitations</h3>
It would have been beneficial to test the implementation on the Basys 3 board. Unfortunately, due to time constraints, this was not possible. The design relies heavily on button inputs, and testing the button functionality directly on the FPGA would have been easier than simulating button presses.

<h3>Timezone Offset</h3>
In the design, we reserved four bits for storing the timezone offset, which can range up to a maximum of 12. However, we were unable to read this offset from the user, as there were not enough switches available.
