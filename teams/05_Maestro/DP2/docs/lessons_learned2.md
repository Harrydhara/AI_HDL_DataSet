# Lessons Learned
A few lessons that we learned thus far is that when thinking about optimization, it does not make sense to optimize everything all at once. Or rather it becomes too big of a task to try and optimize everything in a single go. Thus, we had to narrow down our reasoning for optimizing the system and what would actually have a substancial amount of impact to our peripheral if we made certain optimization choices. Additionally we found it is easier to prove virtually that certain optimizations actually had an impact and how we could show that in certain numbers in order to prove its valility. Also we found that in order to optimize a system we had to make great changes and with those changes came a good amount of personal debugging. Lastly the use of new tools in order to show these optimizations was a new learning curb that the members of this group had to learn how to navigate.
