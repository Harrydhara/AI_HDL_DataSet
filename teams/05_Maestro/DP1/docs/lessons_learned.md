# Lessons Learned
Some lessons that have been learned thus far are a great learning curve for some of us to understand computer architecture and how this design challenge fits into that architecture. Another lesson that we have learned is how to use the command line and its prompts. With these prompts we also learned how to exactly find out what was going wrong within our systems and develop ways to work around those road blocks and really utilize our teams variety of devices, AI choice, and strengths of each member. Finally it would be remiss to not mention the use of AI and how to really learn how to prompt each different system, what each system is better at working at, and how we can get the most out of each prompt without overloading the system.
