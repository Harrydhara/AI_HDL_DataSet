# DP1 Documentation – Team Ingenius

This folder contains all documentation for our Design Phase 1 (DP1) submission in the Arizona AI-HDL Challenge 2026.  
These files describe the design, verification, AI usage, and results of our CRC peripheral.

## 📄 Documentation Files

- **design_methodology.md**  
  Explains how the CRC peripheral was designed and how it integrates with TinyQV.

- **ai_strategy.md**  
  Describes how AI tools were used during development and what parts were manually refined.

- **challenges_faced.md**  
  Lists the real issues we encountered and how we solved them.

- **lessons_learned.md**  
  Summarizes what the team learned during DP1.

- **block_diagram.md**  
  Text-based architecture diagram showing the MMIO wrapper and CRC datapath.

## 📂 Prompts Folder
The `prompts/` directory contains the AI prompt logs used during development.  
These logs show the iterative AI-assisted workflow required by AI-HDL.

## 📂 User Peripherals Folder
The `user_peripherals/` directory contains the CRC peripheral description file:
- `14_ingenius_crc.md` – Detailed documentation of the CRC peripheral (register map, usage, test vectors).
