# Prompts Folder

This folder contains structured prompts used across different phases of our workflow. Each file serves a distinct purpose to ensure clarity, consistency, and traceability.

## 📂 Contents

1. **planning.md**
   - Purpose: Captures initial ideas, strategies, and task breakdowns.
   - Usage: Use this file to outline goals, timelines, and resource allocation before execution begins.
   - Example entries: project milestones, brainstorming notes, task assignments.

2. **design.md**
   - Purpose: Records design validation steps and supporting documentation.
   - Usage: Use this file to verify design decisions, track test cases, and document outcomes.
   - Example entries: design reviews, verification checklists, documentation drafts.

3. **synthesis.md**
   - Purpose: Contains prompts and notes related to synthesis processes.
   - Usage: Use this file to guide synthesis tasks, capture results, and refine outputs.
   - Example entries: synthesis scripts, optimization notes, final outputs.

## 🛠️ Workflow

1. Begin with **planning.md** to establish objectives and scope.
2. Move to **design_verification_and_documentation.md** to validate and record design decisions.
3. Conclude with **synthesis.md** to generate and refine final deliverables.

## ✅ Best Practices

- Keep entries concise and structured.
- Use consistent formatting (headings, bullet points).
- Update files regularly to reflect progress.
- Link related sections across files for easy navigation.
